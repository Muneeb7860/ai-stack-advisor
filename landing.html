The problem

Generic prompts get generic architecture

Ask most AI tools for a stack recommendation and you'll get the same handful of popular names back, with no way to check the reasoning.

⚠ Black-box prompting

One LLM call, one guess. The same "AWS, Kubernetes, Postgres" answer shows up whether you described a weekend side project or a regulated fintech platform.

No way to tell which part of your prompt actually mattered, or whether a detail you mentioned was used at all.

✓ Signal-driven rules

Every recommendation traces back to a specific detected signal — a mentioned vendor, a stated compliance need, a latency target you wrote down.

The same input always produces the same output. Nothing is sampled, nothing is probabilistic.
